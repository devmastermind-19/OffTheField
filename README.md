# OffTheField – Centralized Sports Career Platform

OffTheField is a centralized sports career platform designed to connect students with non-athletic job opportunities in the sports industry.

## Features
- User Registration & Login
- Profile Management
- Job & Internship Portal
- Search & Filtering System
- Admin Dashboard

## Tech Stack
- Backend: Python (Flask)
- Frontend: HTML, CSS
- Database: SQLite (initial)

Basic project structure is included for demonstration as part of SPM assignment.
